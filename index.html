📖 Methodology & References
Table 26 — Consumption
DOT/1000PD = ( Total antimicrobial days ÷ Patient-days ) × 1,000
DDD/1000PD = ( Vials × Strength ÷ WHO DDD ÷ Patient-days ) × 1,000
DDD:DOT = DDD/1000PD ÷ DOT/1000PD [>1=above-standard; <1=shorter; =1=standard]

Table 27 — AMR Resistance
Resistance % = ( Resistant isolates ÷ Total isolates ) × 100
MRSA Bacteraemia = ( Events ÷ Patient-days ) × 1,000
MDRO Incidence = ( Events ÷ Patient-days ) × 10,000

Table 28 — Surgical Prophylaxis [Target ≥80%]
Compliance % = ( Compliant ÷ Total surgical patients ) × 100

Table 29 — Infection Outcomes
CDI Rate = ( Hospital-onset CDI ÷ Patient-days ) × 1,000
SSI Rate = ( SSI events ÷ Total procedures ) × 100

Table 30 — Patient Outcomes
Hospital LOS = Days of hospitalisation ÷ Total patients
Hospital Mortality = ( Deaths ÷ Hospitalisations ) × 100
Sepsis Mortality = ( Sepsis deaths ÷ Sepsis cases ) × 100
Readmission 30d = ( Readmissions ÷ Discharges ) × 100
⚠ DDD/1000PD measures consumption quantity — not clinical appropriateness. Lower values ≠ better stewardship. CAZ-AVI: WHO DDD 6,000 mg refers to ceftazidime component — 2,000 mg/vial used (Option B, WHO-aligned).
