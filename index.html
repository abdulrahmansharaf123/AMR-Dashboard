📖 Methodology & References
Formulas · Data sources · Interpretation · Gulf Guide AMR 2025 Tables 26–30
Table 26 — Consumption KPIs
DOT/1000PD = ( Total antimicrobial days ÷ Patient-days ) × 1,000
DDD/1000PD = ( Vials × Strength ÷ WHO DDD ÷ Patient-days ) × 1,000
DDD:DOT Ratio = DDD/1000PD ÷ DOT/1000PD

Table 27 — AMR KPIs
Resistance % = ( Resistant isolates ÷ Total isolates ) × 100
MRSA Bacteraemia = ( Hospital-onset MRSA events ÷ Patient-days ) × 1,000
MDRO Incidence = ( Hospital-onset MDRO events ÷ Patient-days ) × 10,000

Table 28 — Process KPIs
Surgical Compliance = ( Compliant ÷ Total surgical patients ) × 100 [Target ≥80%]
ASP Acceptance = ( Accepted interventions ÷ Recommended ) × 100
Appropriateness = ( Appropriate ÷ Total evaluated ) × 100

Table 29 — Infection Outcomes
CDI Rate = ( Hospital-onset CDI ÷ Patient-days ) × 1,000
SSI Rate = ( SSI events ÷ Total procedures ) × 100

Table 30 — Patient Outcomes
Hospital LOS = Days of hospitalisation ÷ Total patients
Hospital Mortality = ( Deaths ÷ Hospitalisations ) × 100
Sepsis Mortality = ( Sepsis deaths ÷ Sepsis cases ) × 100
Readmission (30d) = ( Readmissions within 30d ÷ Discharges ) × 100
⚠ DDD/1000PD measures consumption quantity — not appropriateness. Lower values ≠ better stewardship. CAZ-AVI WHO DDD 6,000 mg refers to ceftazidime component only — 2,000 mg per vial used in calculations (Option B, WHO-aligned).
